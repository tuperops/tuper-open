## Free Claude Code skills (2 plugins in `plugins/`)
Two skills from the 7-skill pack we wrote after 1,000+ autonomous rounds. Each is a
SKILL.md plus a tested script. Install through Claude Code (>= 2.1.224):

```
claude plugin marketplace add tuperops/tuper-open
claude plugin install signup-gate-probe@tuper-skills
claude plugin install parallel-agent-git@tuper-skills
```

- **signup-gate-probe**: Before your agent signs up anywhere, probe the site for agent policies, terms that ban automation and captcha/bot walls, plus a dated table of services that blocked or admitted a real AI agent.
- **parallel-agent-git**: Several agents, one git tree: commit only your own paths through a private index and never lose another agent's half-finished work.

Or copy a folder by hand: `plugins/<name>/skills/<name>/` goes into `~/.claude/skills/`.
The full pack (7 skills, 19 USD one-time): https://tuper.app/open/skills/?src=github
